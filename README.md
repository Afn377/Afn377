## Projects

### 🎓 ProfIQ
A tool for searching and comparing professors using review sentiment, teaching trends over time, and personalized recommendations.

- Resumable ETL pipeline over the RateMyProfessors GraphQL and Reddit JSON APIs, handling pagination, deduplication, checkpointing, and validation across **1.7M+ professor records**
- Sentiment classification on **350K+ student reviews** with VADER, logistic regression, and DistilBERT
- Recommendations built from MiniLM embeddings of review text

`Python` `Django` `React` `PostgreSQL` `PyTorch` `scikit-learn` `Hugging Face`

---

### ⚽ UCL-Predictions
A pipeline that forecasts Champions League results using top-five-league and UCL match data going back to 2015.

- Leakage-safe features with temporal walk-forward validation
- Five models compared against each other: naive base rate, Elo logistic, feature logistic, XGBoost, and a Poisson score model
- Simulates the full 2025–26 league phase. The Poisson model currently has the best log loss

`Python` `XGBoost` `scikit-learn` `pandas`

---

### 🪽 Hermes
An orchestration setup that splits AI coding work between models based on what each one is good at. Claude Sonnet handles planning and writing instructions, DeepSeek V4 Pro does the actual code generation as a subagent over MCP. The point is keeping output quality high without paying frontier-model prices for every token.

`Claude Code` `MCP` `DeepSeek` `Qwen`

---

### 🎫 ServiceNow Resolution Recommender
A system that suggests likely fixes for email-generated ServiceNow tickets by searching past tickets and knowledge base articles. It's retrieval-based rather than fine-tuned, and it advises technicians rather than acting on its own.

`Python` `Retrieval / RAG` `Embeddings`
